# 🛒 BigBasket Sales Analysis Dashboard

## 📌 Overview

This project analyzes the BigBasket product dataset using Python and Power BI.

The objective is to identify:

- Product distribution
- Brand performance
- Pricing trends
- Discount analysis
- Customer ratings

---

## 🛠 Tech Stack

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Power BI
- Excel

---

## 📊 Dashboard Features

- KPI Cards
- Product Count by Category
- Top 10 Brands
- Average Sale Price by Category
- Discount Analysis
- Interactive Slicers
